# D0.3 evidence

- `vectorcraft-metrics.json`: actual local measurements in an Electron module
  Web Worker on Apple M1 Pro / macOS arm64. Includes the upstream pin, WASM hash,
  byte counts, imports, timings, provisional geometric comparisons and PDF checks.
- `vectorcraft-dependencies.json`: Cargo metadata for the WASM normal/build graph,
  excluding dev-only dependency edges. No absolute filesystem paths are retained.

Reproduce with the commands in `native/modcut-geom/README.md`. The measurement
runner writes fresh results to the ignored `native/modcut-geom/results/` directory.
Copy metrics here deliberately after inspecting them; do not copy full build logs,
which can contain private absolute paths. The generated PDF remains a local test
artifact and is not committed.

The 30 reference cases in `../vectorcraft-fixtures.json` were generated by original
code in `../spike-fixtures.mjs`, using Paper.js 0.12.18 as an independent provisional
oracle. They cover overlap, containment, disjoint and identical shapes, shared
edges, corner tangency, circles and tangent circles, a star, a hole, self-crossing
input and an original letter-shaped contour. These references have not been
manually approved and are not the final D2.2 golden corpus.

Regenerate from the modCut repo root:

```sh
node --input-type=module <<'JS'
import { writeFileSync } from 'node:fs';
import { createFixtures } from './docs/draw/spike-fixtures.mjs';
writeFileSync('docs/draw/vectorcraft-fixtures.json', JSON.stringify({
  oracle: 'Paper.js 0.12.18; provisional, not manually approved',
  cases: createFixtures(),
}) + '\n');
JS
node --test docs/draw/spike-fixtures.test.mjs
```

The area comparison reorients disjoint contours and holes before integrating
signed curve area. This matters for XOR: opposite winding on disjoint filled
islands must not cancel their measured area. Boundary distance is a **sampled**
Hausdorff estimate (samples at most 0.05 mm apart, distances to nearest curves),
not a proof of the required continuous 0.01 mm bound. Cases and measurements must
be reviewed before using them as acceptance evidence for a production kernel.
